Единое окно управления кластером: автомасштабирование, мониторинг, балансировка нагрузки.

  • Отказоустойчивость и репликация
  • Grafana + Prometheus из коробки

Data Loading

Визуальный конструктор ETL-пайплайнов с поддержкой 200+ источников и потоковой загрузки.

  • Kafka, Flink, Spark интеграция
  • Drag-and-drop визуальный дизайнер
  • Мониторинг пайплайнов в реальном времени

Web IDE

Встроенная среда разработки для SQL: автодополнение, версионирование, совместная работа команды.

  • SQL-редактор с историей и версионированием

Нативная интеграция LLM — работа с данными на естественном языке прямо из платформы.

Производительность

  • Кэш: Memory → SSD → S3

Безопасность

Корпоративный уровень ИБ: RBAC, аудит, шифрование, маскировка данных, мультитенантность.

  • Row- и column-level security
  • Динамическая маскировка данных
  • Аудит всех операций

01Единое хранилище для всех типов данных

Структурированные, полуструктурированные и неструктурированные данные хранятся вместе — без копирования и дублирования. Форматы Parquet, ORC, CSV, JSON.

// 03 · Возможности

Корпоративные возможности движка —
встроены в платформу

Функции промышленного класса: катастрофоустойчивость, тонкая безопасность, оптимизация производительности. Всё готово к production-нагрузке и работает без дополнительных модулей 💻

01 Column Masking & Row Access

Маскирование отдельных колонок и фильтрация строк по ролям пользователя через Apache Ranger

02 Multi-Warehouse

Физическая изоляция compute-ресурсов: отдельные warehouse под ETL, дашборды и ad-hoc аналитику

03 Transparent Data Encryption

Прозрачное шифрование данных на диске через HashiCorp Vault или облачные KMS-сервисы

Failover Group (DR)

Кросс-кластерная асинхронная репликация Primary → Standby с RPO в 15 минут и быстрым переключением

05 Runtime Disk Management

Вывод и замена дисков в compute-нодах без downtime кластера — поштучно, на лету

06 Auto-MV Recommendation

Автоматический анализ workload и рекомендации по материализованным представлениям на базе статистики запросов

07 Cache Multi-Replica

Репликация локального кеша между compute-нодами в shared-data режиме — для строгого p99 SLA под пиковой нагрузкой

08 Password Policy

Корпоративные политики паролей: длина, сложность, срок действия, автоблокировка после неудачных попыток

09 Unity Catalog Metastore

Интеграция с Databricks Unity Catalog и Delta Lake поверх существующего озера данных — без миграции

10 Ranger + Kerberos (SPNEGO)

Корпоративная авторизация через Apache Ranger с Kerberos SPNEGO — готовая связка для Hadoop-сред

// 04 · Внедрение

Как начать работу с Selena

Четыре сценария интеграции в IT-ландшафт вашей компании — без слома текущей инфраструктуры 💡

01 Нет DWH → строим с нуля

Новая установка

Если у вас ещё нет хранилища данных — Selena строит единую, масштабируемую систему для аналитики, AI/ML и отчётности с нуля. Без legacy-ограничений.

02 Есть DWH → расширяем возможности

Новые аналитические сценарии

Текущий DWH остаётся нетронутым. Selena подключается для реализации новых кейсов: big data аналитика, машинное обучение, потоковая обработка.

03 Устаревший DWH / Datalake → мигрируем

Миграция с legacy систем

Переводим аналитическую инфраструктуру на современную Lakehouse-платформу. Бизнес-логика и данные сохраняются, стоимость и сложность снижаются.

04 Несколько хранилищ → единая платформа

Консолидация Data Platform

Несколько разрозненных хранилищ, озёр и BI-систем объединяются в централизованную Lakehouse-платформу. Единое управление данными и качеством.
